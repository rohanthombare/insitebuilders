# Insite Builders - Premium Digital Business Card

A production-ready, highly polished digital visiting card web application built with pure HTML, CSS, and Vanilla JavaScript configured for GitHub Pages (`https://rohanthombare.github.io/insitebuilders/`).

## 🚀 How to Deploy to GitHub Pages
1. Download and extract all files (`index.html`, `card.html`, `style.css`, `script.js`, `card.js`, `contact.vcf`).
2. Push them to your GitHub repository `insitebuilders`.
3. Go to your repository **Settings** -> **Pages** -> Ensure it is set to deploy from the `main` or `master` branch.
4. Your site will automatically run from `https://rohanthombare.github.io/insitebuilders/` and dynamically route all share links correctly!

## 🛠 How to Customize
- **Phone Number & Details**: Update `card.html` and `card.js`.
- **Colors**: Modify the `:root` variables in `style.css`.
- **Logo**: Replace the `.logo-placeholder` div with an `<img>` tag in `index.html` and `card.html`.
